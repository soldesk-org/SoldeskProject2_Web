너는 IT 부트캠프 팀 프로젝트 발표용 PPT를 만들어주는 전문 프레젠테이션 디자이너야.
아래 프로젝트 정보를 바탕으로 실제 발표에 쓸 수 있는 완성도 높은 PPT를 만들어줘.

---
## 1. 프로젝트 개요

- 프로젝트명: 잇티웨이 (Eatty way)
- 한 줄 소개: AI 기반 맛집 검색·추천 및 커뮤니티 서비스
- 컨셉: 사용자가 자연어로 원하는 분위기/음식/위치를 말하면 AI가 실제 카카오 지도 데이터를 기반으로
  맛집을 추천해주고, 영수증 인증 기반의 신뢰도 높은 리뷰, 실시간 오픈채팅, 음식 취향 테스트(음BTI),
  주차장/길찾기 등 식사 전후 경험까지 하나의 서비스로 묶은 통합 맛집 플랫폼
- 팀 구성: 5인 팀 (백엔드/프론트엔드/인프라/AI 전 영역을 팀원이 나눠 담당)
- 개발 기간: 2026-07-17(핵심 인프라 구축) ~ 2026-07-29(현재), 약 2주간 22개 기능 모듈을 순차 개발
- 대상 사용자: 일반 회원(맛집을 찾고 리뷰를 남기는 소비자), 사업자 회원(자신의 매장을 관리하는 점주),
  관리자(신고/회원/콘텐츠를 관리하는 운영자) — 3가지 역할 기반 서비스

---
## 2. 기술 스택

**백엔드**
Java, Spring Boot, Spring Security, JPA/Hibernate, MariaDB, Redis, JWT, OAuth 2.0, Tomcat, Maven

**프론트엔드**
HTML, CSS, JavaScript(바닐라, 프레임워크 미사용), Tailwind CSS, WebSocket(STOMP)

**AI/외부 연동**
Python/FastAPI(3개의 보조 서버: 사업자등록증/영수증 OCR, AI 키워드 추천, 리뷰 욕설 필터링),
Naver Maps API(지도 렌더링, 길찾기), Kakao API(장소 검색, 소셜 로그인)

**인프라/개발도구**
Docker, Git, Playwright(E2E 테스트), Azure VM

---
## 3. 시스템 아키텍처 설명 (다이어그램 슬라이드로 만들어줘)

전체 구조는 3층으로 구성돼:
1. **프론트엔드**: 정적 HTML + Tailwind CSS + 바닐라 JS. 별도 프레임워크 없이 각 화면(explore, recommend,
   mypage, chat, admin 등)을 독립 페이지로 구성하고 공용 인증 모듈(api.js)을 공유
2. **백엔드(Spring Boot)**: REST API + WebSocket(STOMP, 오픈채팅 전용) 제공. JWT 기반 인증(Access/Refresh
   토큰을 Redis에서 관리), 회원 등급별(일반/사업자/관리자) 접근 제어
3. **데이터/외부 연동 계층**:
   - MariaDB: 회원, 리뷰, 즐겨찾기, 채팅, 신고 등 서비스 고유 데이터 저장(약 30개 테이블, 7개 도메인)
   - Redis: 로그인 실패 잠금, 로그인 세션(Access/Refresh 토큰), OAuth state 관리
   - 외부 API: 카카오 로컬 API(음식점 실시간 검색, DB에 음식점 원본 데이터 저장하지 않음 — 카카오
     운영정책 준수), 네이버 지도/길찾기, 카카오·네이버·구글 소셜 로그인
   - Python(FastAPI) 보조 서버 3개: (1) 사업자등록증/영수증 OCR(Gemini API + RapidOCR + 국세청 진위확인),
     (2) 자연어 추천 키워드 추출 AI(Qwen2.5-1.5B), (3) 리뷰 욕설 필터링(korcen 오픈소스 라이브러리)

핵심 설계 포인트로 강조해줘: "카카오 지도 데이터는 저장하지 않고 항상 실시간 조회, 우리 서비스만의
부가정보(리뷰/즐겨찾기/사업자 인증)만 우리 DB에 저장" — 이게 이 프로젝트의 가장 중요한 아키텍처 결정임.

## 4. 핵심 기능 목록 (카테고리별로 슬라이드 나눠서 구성해줘)

### 4-1. 회원/인증
- 일반 회원가입 / 사업자 회원가입(사업자등록증명원 OCR+원본확인+국세청 진위확인 자동 검증)
- 로그인/로그아웃, 로그인 상태 유지(자동로그인), 로그인 5회 실패 시 30분 계정 잠금
- 소셜 로그인(카카오/네이버/구글) — 기존 가입 이메일과 겹치면 자동 계정 연동
- 이메일/비밀번호 찾기, 회원정보수정, 프로필 사진 등록, 회원 탈퇴
- 비밀번호는 Argon2(단방향 해싱), 전화번호는 AES-256-GCM(양방향 암호화)+HMAC-SHA256(중복확인용 단방향
  해시) 이중 보호, 로그인/회원정보 수정 구간은 HTTPS 전송 암호화 적용

### 4-2. 음식점 검색/지도
- 카카오 로컬 API 기반 실시간 음식점/카페 검색(가게명+메뉴명 통합 검색)
- 카테고리별(한식/양식/중식 등 10종) 지도 마커, 가격대 필터
- 인근 유료주차장 실시간 조회(서울 열린데이터광장 연동)
- 자동차 길찾기(경로/거리/소요시간/택시요금, 네이버 지도 Direction API)

### 4-3. AI 추천
- 자연어 질문("강남역 근처 조용한 파스타집 추천해줘") → AI가 위치/카테고리/분위기 키워드 추출 →
  카카오 실시간 검색으로 실제 장소 추천
- 추천 결과에 대한 사용자 피드백(도움됨/안됨) 수집
- 추천 후속코스 제안(식사 후 근처 카페/공원 추가 추천)

### 4-4. 리뷰/영수증 인증
- 영수증 OCR 인증(매장명 자동 대조) 기반 리뷰 작성 — 인증 안 된 리뷰는 등록 불가(신뢰도 확보)
- 별점+긍정/부정 키워드 태그(각 10종)+자유 텍스트 리뷰, 수정/삭제
- korcen 오픈소스 기반 욕설/비속어 자동 필터링
- 리뷰 신고 기능(사유 선택형), 관리자 처리(승인/반려)

### 4-5. 마이페이지
- 프로필/즐겨찾기/방문기록(영수증 인증된 리뷰)/내 리뷰 관리
- 검색 기록 조회/삭제
- 음BTI(음식 취향 유형 테스트) — 12문항, 4축 성향 기반 유형 진단 및 결과 저장

### 4-6. 커뮤니티/부가 기능
- 오픈채팅(잇티챗): 참가코드로 입장하는 실시간 채팅방(WebSocket/STOMP), 방장 방 폭파, 최대 인원 설정,
  채팅 욕설 필터링, 채팅/채팅방 신고
- 음식 룰렛: 카테고리를 골라 룰렛을 돌려 오늘 뭐 먹을지 랜덤 추천 + 주변 실제 맛집 연결(백엔드 없는 순수
  프론트 기능)

### 4-7. 관리자
- 회원 정지/정지해제, 리뷰 강제 삭제, 리뷰/채팅 신고 처리(대기중/처리완료/반려)
- 관리자 대시보드(회원 통계, 신고 현황), API 서버 상태 모니터링
- Spring Security 기반 관리자 전용 권한 분리(`/api/admin/**`만 필터 적용, 나머지는 기존 방식 유지 —
  "필요한 곳에만 인프라를 추가한다"는 팀의 설계 원칙을 보여주는 사례로 언급해줘)

## 6. PPT 구성 요청사항

아래 순서로 슬라이드를 구성해줘. 슬라이드 수는 15~20장 내외, 발표 시간 10~15분 기준으로 만들어줘.

1. 표지 (프로젝트명 "잇티웨이(Eatty way)", 한 줄 소개, 팀명/팀원 — 팀명/팀원은 [팀명 입력]/[팀원 입력]
   같은 placeholder로 남겨줘)
2. 기획 배경 및 문제 정의 (기존 맛집 앱들이 리뷰 신뢰도/조작 문제가 있다는 점, 우리 서비스는 영수증
   인증으로 이를 해결한다는 차별점 강조)
3. 서비스 컨셉 및 핵심 차별점 3가지 요약 (① 영수증 인증 리뷰 ② 자연어 AI 추천 ③ 카카오 실시간 데이터
   기반, 자체 DB 미저장)
4. 전체 기능 맵(마인드맵 또는 아이콘 그리드 형태로 22개 기능을 6개 카테고리로 그룹핑해서 한눈에)
5. 기술 스택 슬라이드(카테고리별 로고/아이콘 배치: 백엔드/프론트엔드/AI/인프라)
6. 시스템 아키텍처 다이어그램(3장 내용을 도식화 — 프론트엔드/백엔드/DB+외부API 3단 구조)
7. ERD 요약(7개 도메인 그룹과 대표 테이블만 간단히 — 회원/사업자/음식점/영수증/리뷰/추천 도메인)
8. 핵심 기능 상세 1 — 회원/보안(다중 회원가입, 소셜로그인, 암호화 방식)
9. 핵심 기능 상세 2 — 음식점 검색/지도(카카오 연동, 필터, 마커)
10. 핵심 기능 상세 3 — AI 추천(자연어 질의 → 추천 플로우를 화살표 다이어그램으로)
11. 핵심 기능 상세 4 — 영수증 인증 리뷰(OCR 인증 플로우)
12. 핵심 기능 상세 5 — 오픈채팅
13. 핵심 기능 상세 6 — 마이페이지/음BTI
14. 핵심 기능 상세 7 — 관리자 페이지
15. 개발 과정에서의 기술적 도전과 해결(예: 카카오 API 정책 준수를 위한 아키텍처 재설계, 실시간 채팅
    구현, 보안 설계 등 — 실제 트러블슈팅 경험이 있었다는 톤으로)
16. 팀원별 역할 분담
17. 향후 개선 계획(예: 사업자 대시보드 고도화, AI 추천 정확도 개선, 모바일 앱화 등 — 팀에서 자유롭게
    채울 placeholder로)
18. 마무리/Q&A 슬라이드

디자인 톤은 깔끔하고 모던한 IT 스타트업 스타일, 메인 컬러는 오렌지 계열(#fd6d4a ~ #fea255 그라데이션)을
포인트 컬러로 써줘. 텍스트는 너무 빽빽하지 않게, 슬라이드당 핵심 문장 위주로 요약하고 나머지는 발표자
스크립트로 따로 정리해줘.
