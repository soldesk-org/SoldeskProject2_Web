## SMS(문자) 본인인증 추가 (2026-07-18 요구사항 추가)
------------------------------------------------------------------------
이메일 인증처럼 전화번호도 실제로 본인 소유인지 SMS 인증번호로 확인하는 절차를 추가하기로 함 (기존에는 전화번호를 입력만 받고 인증은 안 하는 상태였음)
- 사용 대행사: 뿌리오(Ppurio) — https://www.ppurio.com/
- 문자 API: https://github.com/bizppurio-api/api-documentation , https://bizppurio.github.io/ (2026-07-20 확인 결과 구버전 문서였음 — 실제 스펙은 뿌리오 콘솔 "연동개발(API)" 메뉴의 Swagger 문서 기준, 42번째 줄 가이드 참고)
- 비용(기본단가, 부가세 포함): 단문 21.82원(24원), 장문 45.46원(50원), 포토 90원(99원)
- 혜택: 뿌리오 신규 기업회원 전환 후 신청 시 무료문자 1,000건 지급 (2026-07-01~07-31 이벤트, 최초 1회 한정)
- 인증번호 문자는 참고 이미지처럼 발송 (`본인확인 인증번호는 [319287] 입니다.` 형식)
- 상세 연동 스펙(토큰 발급/SMS 발송 API, 계정 관리, 공통 인증 설계)은 [00.공통/SMS-인증-Ppurio-연동-가이드.md](../00.공통/SMS-인증-Ppurio-연동-가이드.md) 참고
