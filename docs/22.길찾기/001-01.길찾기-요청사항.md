## 요청사항 원문 요약
------------------------------------------------------------------------
현재 검색한 음식점에 길찾기 기능을 추가해달라는 요청(2026-07-27). 길찾기 버튼을 누르면 현재 위치에서
그 음식점까지 경로를 지도에 표시해주고, 소요시간·요금(통행료/택시요금)도 같이 보여줬으면 좋겠다는 것.
사용자가 "Directions 5"라는 이름의 API가 따로 있다고 직접 언급함 — 확인해보니 NCP(네이버클라우드플랫폼)
Maps 상품군의 "Direction 5"(자동차 길찾기) API였다.

## 배경 — 이미 있던 지도 인프라와의 관계
------------------------------------------------------------------------
이 프로젝트는 지도 렌더링에 이미 NCP Maps JS SDK를 쓰고 있다(`tmp-map-test.html`의
`<script src="https://oapi.map.naver.com/openapi/v3/maps.js?ncpKeyId=...">`). 이 키(`ncpKeyId`)는
브라우저에 그대로 노출되는 **공개용 키**로, 지도를 그리는 용도로만 쓰인다.

Direction 5는 이것과 다른 API다 — NCP 콘솔에서 별도로 발급받는 **Client ID/Secret 쌍**으로 인증하는
서버 전용 REST API다(`X-NCP-APIGW-API-KEY-ID`/`X-NCP-APIGW-API-KEY` 헤더). 브라우저에서 이 Secret을
그대로 노출하면 안 되므로, 프론트가 직접 호출할 수 없고 **우리 서버가 대신 호출해주는 프록시**가 필요하다
— 08(영수증OCR)/06(소셜로그인) 등에서 이미 써온 "서버가 외부 API를 대신 불러주는" 패턴과 같다.

사용자가 이미 이 Client ID/Secret 키를 갖고 있어서(발급 절차 안내 없이) 바로 연동을 진행했다. Client
ID는 공교롭게도 지도 렌더링 키(`i99edc9due`)와 동일했다 — NCP 콘솔에서 하나의 애플리케이션에 여러 API를
함께 활성화해두면 Client ID는 공유되고 Secret만 API별로 다르게 발급되는 구조로 보인다(확인된 사실은
아니고 관찰에 근거한 추정).

## API 조사 결과
------------------------------------------------------------------------
`curl`로 직접 호출해서 실제 응답을 확인했다:
```
GET https://maps.apigw.ntruss.com/map-direction/v1/driving?start={경도},{위도}&goal={경도},{위도}
Headers: X-NCP-APIGW-API-KEY-ID, X-NCP-APIGW-API-KEY
```
응답에 경로 좌표(`path`, [경도,위도] 배열), 거리(m), 소요시간(ms), 통행료(`tollFare`), 택시요금
(`taxiFare`), 유류비(`fuelPrice`), 턴바이턴 안내(`guide`), 도로 구간 정보(`section`, 혼잡도 포함) 등이
전부 들어있음을 확인. 이번 범위에서는 경로 좌표+거리+소요시간+통행료+택시요금만 쓰고, 턴바이턴 안내/
도로 구간별 혼잡도는 이번 범위 밖으로 정함(아래 "이번 범위에서 제외된 것" 참고).

## 이번 범위 정리
------------------------------------------------------------------------
- 음식점 상세 화면에 "길찾기" 버튼 추가
- 버튼 클릭 시 브라우저 현재 위치(`navigator.geolocation`) → 그 음식점 좌표까지 자동차 경로 조회
- 지도에 경로선(Polyline) 표시, 지도 화면을 경로 전체가 보이도록 자동 조정
- 거리/소요시간/통행료/택시요금 텍스트로 요약 표시
- docs 4종 문서

------------------------------------------------------------------------
## 이번 범위에서 제외된 것
------------------------------------------------------------------------
- **턴바이턴 안내 문구**(`guide` 필드): API 응답엔 있지만 이번엔 경로선+요약 정보만 표시. 필요해지면
  추가 개발 가능
- **도로 구간별 혼잡도**(`section` 필드): 위와 동일
- **도보/대중교통 경로**: 이번 API는 자동차(운전) 경로만 지원. NCP에 도보/대중교통 전용 API가 별도로
  있는지는 이번에 조사하지 않음
- **경유지(waypoints)**: 이번 API가 지원하는지 확인 안 함, 출발지→목적지 단일 구간만 구현
