## 기능 정리하기
------------------------------------------------------------------------
현재 해당 기능은 프론트 연결하지 않고 개발만 하기
로그인 시 이메일, 비밀번호를 입력받아서 요청하면
먼저 비밀번호는 단방향 암호화를 진행하였기 때문에 입력한 비밀번호를 암호화 환경 알고리즘을 사용하여 암호화 후 DB에 있는 값이랑 대조하여 확인하기
해당 이메일이 존재하는지, 비밀번호가 일치한지를 확인하기
일치하지 않는 경우 아이디 또는 비밀번호가 일치하지 않습니다 라고 하기
일치하는 경우 로그인에 성공하였습니다 라고 하고 메인 페이지로 이동하기 (아직 개발하지 않음)

------------------------------------------------------------------------
##  입력받는 값
------------------------------------------------------------------------
이메일, 비밀번호, 닉네임, 전화번호
