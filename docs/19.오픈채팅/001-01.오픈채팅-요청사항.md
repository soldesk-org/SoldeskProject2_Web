# 오픈채팅

------------------------------------------------------------------------
## 실행 환경
------------------------------------------------------------------------
사용하는 툴
- STS, VS Code
사용하는 코드
- Spring Boot(백엔드, WebSocket/STOMP), Python/FastAPI(17의 review-filter 재사용)
작업 영역
- Project2 (신규 chat 패키지), 관리자 페이지(admin-test.html)

## 요청사항 원문 요약
------------------------------------------------------------------------
```
[ UI 수정 필요 ] 오픈채팅
   - 카카오톡 오픈채팅 처럼 참가코드를 생성해서 맛집 추천이나 대화
   - 실시간 채팅 (Socket)
   - 채팅방 방 폭파
   - 오픈채팅 신고 기능 또는 클린봇
```
카카오톡 오픈채팅과 비슷하게, 참가코드를 공유해서 들어오는 채팅방을 만들고 실시간으로 대화할 수 있게
해달라는 요청. 참가코드는 "랜덤하게 생성되게, 6자리 또는 8자리(영문 숫자 섞인)"으로 구체적으로 지정됨.

"신고 기능 또는 클린봇" 중 어느 쪽으로 만들지 확인 질문(AskUserQuestion)에 "korcen도 해서 검열도 하고
신고 기능도 해줘 신고 기능은 그 채팅 또는 그 채팅방 둘 다 신고 가능하게 하고 그럼 관리자 페이지에서도
그 신고 리스트에 저거들도 들어가게 나눠놔야 하고 그리고 DB 컬럼도 추가해야 하는데 전체 다 해줘"로 답해서
**둘 다** 만들기로 확정 — 클린봇(17.리뷰-필터링에서 이미 붙인 korcen 필터 재사용)과, 메시지/채팅방 둘 다
신고 가능한 신고 기능을 함께 구현하고, 관리자 페이지의 기존 "신고 관리" 영역에 채팅 신고를 별도 목록으로
추가해달라는 요청.

------------------------------------------------------------------------
## 배경
------------------------------------------------------------------------
이 프로젝트는 지금까지 순수 REST API만 있었고 WebSocket/실시간 통신 기능이 전혀 없었다 — 이번이 최초 도입.
클린봇은 새로 만들지 않고 17(리뷰-필터링)에서 이미 붙인 korcen 기반 `ReviewFilterClient`(fail-open 설계)를
그대로 재사용했다 — 리뷰 본문이든 채팅 메시지든 "텍스트 하나를 검사해서 욕설 여부를 반환"하는 동작은
동일하기 때문. 신고 기능도 16(리뷰-신고)의 상태 모델(PENDING/RESOLVED/REJECTED)과 신고 사유 목록
(`ReportReasonCatalog`)을 그대로 재사용했다.

## 이번 범위 정리
------------------------------------------------------------------------
- 참가코드로 들어오는 오픈채팅방 생성/참가/목록/나가기
- 참가코드는 영문 대문자+숫자 섞인 6자리 또는 8자리 랜덤 생성(기본 8자리), 중복 방지
- 실시간 채팅 — WebSocket(STOMP) 기반, 방 참가자에게 즉시 브로드캐스트
- 채팅방 방 폭파 — 방장만 가능, 대화 내용(메시지)을 물리 삭제하고 방 상태를 CLOSED로 전환
- korcen 클린봇 — 메시지 전송 시 욕설/비속어가 감지되면 브로드캐스트되지 않고 보낸 사람에게만 거부 알림
- 신고 기능 — 메시지 단위, 채팅방 단위 둘 다 가능(회원이 선택)
- 관리자 페이지 — 채팅 신고를 리뷰 신고와 별도 목록으로 조회/처리(완료/반려), 신고된 메시지/방을 강제
  삭제/폭파할 수 있는 관리자 전용 액션 추가
- 테스트 페이지 `chat-test.html` 신규

------------------------------------------------------------------------
## 이번 범위에서 제외된 것
------------------------------------------------------------------------
- 채팅방 검색/탐색(공개 방 목록 브라우징) — 카카오톡 오픈채팅처럼 참가코드를 아는 사람만 들어올 수 있고,
  전체 공개 방 목록을 보여주는 기능은 요청에 없어 만들지 않음
- 1:1 개인 채팅 — "오픈채팅"이라는 요청 자체가 여러 명이 참가코드로 모이는 그룹 채팅을 의미해서, 별도
  1:1 다이렉트 메시지는 범위 밖
- 메시지 읽음 표시, 타이핑 중 표시 등 카카오톡의 부가 UX — 요청에 없어 제외
- 채팅방 초대(참가코드 없이 특정 회원을 바로 초대) — 참가코드 공유 방식만 지원
- 파일/이미지 전송 — 텍스트 메시지만 지원
- 채팅 메시지 페이지네이션 — 최근 50건만 불러오는 단순한 범위(001-02 참고)
