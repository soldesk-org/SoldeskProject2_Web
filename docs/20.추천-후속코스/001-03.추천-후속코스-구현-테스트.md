## 2. 검증 (2026-07-25, 실 서버 + 실제 AI 서버 + 실제 카카오 API)
------------------------------------------------------------------------
### 2-1. 환경 준비
이번 검증은 컴퓨터를 옮긴 뒤 처음 진행한 것이라(자세한 내용은 CLAUDE.md 참고), 새 컴퓨터에서 AI 추천
Python 서버(`recommendation_api.py`)의 `venv`가 이전 컴퓨터 경로(`C:\Users\sdedu01\...`)를 그대로 갖고
있어 실행이 안 되는 문제가 있었다 — `venv/pyvenv.cfg`의 `home`/`executable`/`command` 경로를 이 컴퓨터의
Python 3.11 설치 경로로 직접 수정해서 해결(두 컴퓨터 모두 Python 3.11.9라 버전은 문제없었음). DB VM도
자동 종료 상태여서 사용자가 Azure Portal에서 직접 켜준 뒤 진행했다.

### 2-2. 기존 추천 API(`/api/recommendation/query`)로 앵커 확보
"강남역 근처 맛있는 파스타집 추천해줘" 요청 → 1위 결과 "미도인 강남"(x=127.027187506638,
y=37.5021014097588) 확보. (curl로 한글 텍스트를 보낼 때 `-d`로 직접 넘기면 인코딩이 깨지는 문제가 있어,
UTF-8 파일로 저장 후 `--data-binary @file`로 보내서 해결 — 이 프로젝트에서 반복적으로 겪어온 이슈.)

### 2-3. PARK 타입 검증 (필터링 버그 2건 발견 및 수정)
1차 시도: `역삼문화공원 제2호공영주차장`, `역삼문화공원 제1호공영주차장` 같은 **주차장**이 결과에 섞여
나옴 — `category_name`에 "공원"이라는 글자가 포함돼 있어서(예: "교통,수송 > 교통시설 > 주차장 > 공영주차장"이
아니라 실제로는 상호명에 "공원"이 들어간 주차장) 필터를 통과했던 것. `category_name`에 "주차장"이
포함되면 제외하도록 수정.

2차 시도: `메가MGC커피 역삼문화공원점`(카페)이 결과에 섞여 나옴 — 공원 이름을 딴 카페 지점이라 역시
"공원" 텍스트 필터를 통과함. `category_name` 최상위가 "음식점"인 것도 제외하도록 추가 수정.

3차 시도(최종): 5곳 모두 실제 공원(역삼문화공원, 역삼문화공원 휴가든, 역삼은행나무공원, 누리숲어린이공원,
논현무궁화공원)으로 정상 확인.

### 2-4. CAFE 타입 검증
같은 앵커로 요청 → 헬로룸카페, 히히냥냥(고양이카페), 공차 강남2호점, 퍼즐팩토리 강남점, 카페온화
강남점 5곳이 거리순(0~38m)으로 정상 반환됨을 확인. 전부 `category_name`이 "음식점 > 카페"로 시작하는
실제 카페였음.

### 2-5. AI 분석 반영 확인
두 타입 모두 응답 `message`에 AI가 추출한 분위기 키워드가 괄호로 포함됨을 확인(예: "...(산책하기 좋은,
공원)", "...(감성)") — `RecommendationClient.analyzeKeywords()`가 실제로 Python `/api/keywords`를
호출해서 LLM 분석 결과를 받아오고 있음이 실측으로 확인됨.

## 3. 후속 수정 (2026-07-25, 같은 날) — 도보 코스 시각화 + 닫기 버튼 + 카테고리 마커 이미지
------------------------------------------------------------------------
001-02 2-8~2-10장 참고. 세 가지를 프론트(`recommend-test.html`)에 순서대로 추가:

1. **도보 코스 시각화** — 음식점 → 가까운 순서 1·2·3위를 네이버 지도 `Polyline`(점선)으로 연결, 마커에
   순서 번호 배지 추가. 실제 도로 경로가 아니라 직선 거리 기준이라는 안내 문구를 결과 메시지에 덧붙임.
2. **후속 추천 "닫기" 버튼** — 사용자가 스크린샷으로 "버튼이 하나만 있는데?" 지적 → `followupDismissBtn`
   추가, 클릭 시 후속 추천 섹션을 그냥 숨김.
3. **추천 마커를 메인 지도와 같은 카테고리 이미지로 통일** — `CATEGORY_MARKER_ICONS`(메인 지도
   `tmp-map-test.html`과 동일한 10개 PNG, 27×35px) + 카카오 `category_name` 문자열 키워드 매칭 함수
   `categoryMarkerIcon()` 추가. 매칭 안 되면 기존 파란 번호 마커로 대체.

세 가지 다 백엔드 변경 없이 순수 프론트 렌더링만 수정 — 컴파일/서버 재기동 불필요, 정적 리소스만
재배포(`cp`)하고 브라우저 새로고침으로 즉시 반영 확인.
