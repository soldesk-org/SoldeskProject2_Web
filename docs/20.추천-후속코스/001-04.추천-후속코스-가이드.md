## 1. 서버 접속 정보
------------------------------------------------------------------------
- Spring 로컬 개발 서버: `http://localhost:8081`
- AI 분석용 Python 서버(recommendation_api.py): `http://localhost:8000` — 이 서버가 꺼져 있으면
  후속 추천 자체가 실패한다(메인 추천 `/api/recommendation/query`와 동일한 의존성).

------------------------------------------------------------------------
## 2. 프론트 연동 흐름
------------------------------------------------------------------------
1. `POST /api/recommendation/query`로 메인 추천을 받은 뒤, 결과 배열의 1위(`recommendations[0]`)를
   기억해둔다(좌표 `x`/`y`, 이름 `place_name`)
2. 추천이 끝나면 `PARK`/`CAFE` 중 하나를 프론트에서 랜덤으로 골라 안내 문구를 보여준다(예: "밥 먹고
   산책 어때요? AI가 추천해드릴게요")
3. 사용자가 "괜찮아요"를 누르면 `POST /api/recommendation/nearby-course`를 호출한다
4. 응답의 `places` 배열을 카드/마커로 보여준다 — 없으면(`places: []`) "찾지 못했어요" 안내

------------------------------------------------------------------------
## 3. 알아둘 것
------------------------------------------------------------------------
1. 이 API는 로그인 여부와 무관하게 항상 동작한다(`Authorization` 헤더 불필요)
2. `type`은 `PARK` 또는 `CAFE`만 허용 — 다른 값이면 `400 INVALID_INPUT`
3. 결과는 항상 거리순(가까운 순)으로 온다 — `distanceMeters`가 `null`이면 카카오가 거리를 안 준 경우(거의
   없음)
4. 매번 다른 앵커 좌표로 요청해야 한다 — 새로 추천을 받을 때마다 프론트가 새 1위 결과의 좌표로 갱신해서
   보내야 함(이전 앵커를 계속 재사용하면 엉뚱한 위치 기준으로 검색됨)

## 4. API 상세
------------------------------------------------------------------------
### 4-1. 후속 코스 추천
```
POST http://localhost:8081/api/recommendation/nearby-course
Content-Type: application/json

{ "type": "CAFE", "anchorName": "미도인 강남", "x": 127.027187506638, "y": 37.5021014097588 }
```
응답(200)
```json
{
  "type": "CAFE",
  "message": "미도인 강남 근처에서 갈 만한 카페 5곳을 찾았어요(감성).",
  "places": [
    {
      "placeId": "1062621432", "placeName": "헬로룸카페",
      "categoryName": "음식점 > 카페 > 테마카페",
      "addressName": "서울 강남구 역삼동 619-3",
      "roadAddressName": "서울 강남구 강남대로102길 16",
      "placeUrl": "http://place.map.kakao.com/1062621432",
      "x": "127.027182985214", "y": "37.5021077178398", "distanceMeters": 0
    }
  ]
}
```

## 5. 테스트 페이지
------------------------------------------------------------------------
`recommend-test.html`에 추천 완료 후 자동으로 후속 추천 카드가 뜬다(보라색 박스, "괜찮아요"/"닫기" 버튼
둘 다 있음 — 필요 없으면 "닫기"로 바로 접을 수 있다). "괜찮아요"를 누르면 카페는 주황색(☕), 공원은
초록색(🌳) 마커로 지도에 표시된다. 가까운 순서 1~3위는 음식점에서부터 번호 순서대로 점선(Polyline)으로
이어서 "도보 코스"처럼 보여준다(2026-07-25 추가) — 실제 도로를 따라가는 경로가 아니라 직선 거리 기준
순서 표시이며, 이 프로젝트가 쓰는 지도/장소 API에는 도보 경로 계산 기능이 없어서 정확한 turn-by-turn
안내는 지원하지 않는다(001-02 2-8장). 4위 이후 결과는 "다른 후보"로 회색 마커만 남고 코스에는 포함되지
않는다.

메인 추천 결과(1~5위) 자체의 마커도 2026-07-25부터 메인 지도(`tmp-map-test.html`)와 같은 카테고리별
이미지(한식/양식/중식/일식/분식/패스트푸드/아시안/술집/뷔페/카페-디저트)로 표시된다(001-02 2-10장) —
카테고리를 못 알아낸 결과만 기존 파란 번호 마커로 나온다.

  001-02 2-1장)
