# 리뷰 작성/조회 기능
------------------------------------------------------------------------
> **작성 방식에 대한 안내**: 이 기능은 01~08과 달리 별도 요청사항 문서 없이 07(음식점-메뉴-검색)/08(영수증OCR)
> 작업 도중 지도 테스트 페이지 연동을 위해 바로 구현되었다. 이 문서는 **사후(2026-07-22)에 실제 구현된 내용을
> 근거로 역으로 정리한 것**이라, 다른 폴더의 001-01처럼 팀이 사전에 합의한 원문 요구사항이 아니다 — "왜
> 이렇게 만들었는가"의 배경은 실제 대화/결정 맥락을 최대한 반영했다.

## 배경
------------------------------------------------------------------------
07(음식점-메뉴-검색) 001-01 요청사항 원문에 이미 "리뷰"라는 개념이 등장했지만(태그/카테고리 정리, 리뷰 캐시
필드 등), 리뷰를 실제로 작성·조회하는 기능 자체는 07의 범위에서 명시적으로 제외되어 있었다(07 001-02 1-0장
3번 — "리뷰는 주혁이 별도로 만들 도메인으로 분류"). 이후 실제 작업 순서는:

1. 07에서 지도 위에 음식점 마커를 표시하고 클릭하면 상세 정보가 나오는 기능을 완성
2. 08에서 영수증 업로드 → OCR → 방문 인증 판정 기능을 완성(리뷰에 "영수증 인증" 뱃지를 붙이기 위한 선행 작업)
3. 위 두 가지를 지도 테스트 페이지(`tmp-map-test.html`)에서 실제로 눈으로 확인하려면 "리뷰를 실제로 쓰고
   보는" 화면이 있어야 검증이 됨 → 정식 "3. 사용자 기능" 단계를 기다리지 않고, 검증에 필요한 최소 기능
   (작성 + 조회)만 먼저 구현

즉 이 기능은 **정식으로 기획된 리뷰 도메인의 축소판**으로 시작했다. **(2026-07-22 추가)** 이후 "리뷰
작성·수정·삭제, 즐겨찾기 등록·취소, 검색 기록 조회·삭제 다 되어야 해"라는 확정 지시로 수정·삭제가
추가되어, 축소판이 아니라 사실상 정식 CRUD를 갖추게 됐다(7장 갱신 참고). 신고/사진 첨부/댓글은 여전히
범위 밖.

**(2026-07-23 정책 변경)** "영수증 리뷰로만 등록 가능하게 해줘, 일반 리뷰 안 됨 무조건 영수증 인증이
필요함"이라는 확정 지시로, 원래 선택이었던 영수증 인증 연결이 필수로 바뀌었다 — 이제 영수증 인증 없이는
리뷰 작성 자체가 불가능하다(리뷰 신뢰도를 높이려는 목적, 상세 근거는 001-02 2-3장).

## 기능 정리하기
------------------------------------------------------------------------
- 로그인한 회원이 특정 음식점(카카오 place id 기준)에 별점(1~5) + 키워드 태그(선택) + 자유 텍스트(선택,
  둘 중 하나는 있어야 함) 리뷰를 남길 수 있다
- **(2026-07-23 정책 변경)** 영수증 업로드(08)로 방문 인증에 성공한 경우에만 리뷰를 작성할 수 있다 — 영수증
  인증 없는 일반 리뷰는 더 이상 허용되지 않는다(예전엔 선택이었음)
- 누구나(비로그인 포함) 특정 음식점의 리뷰 목록을 조회할 수 있다
- 작성 중인 리뷰를 임시저장(초안 자동저장)해서, 화면을 나갔다 다시 들어와도 이어 쓸 수 있어야 한다(2026-07-22
  요청사항 추가 — "리뷰 적다가 잠시 나갔다 올 때 임시저장도 가능하게")
- **(2026-07-22 추가)** 본인이 쓴 리뷰는 수정/삭제할 수 있어야 한다 — 다른 회원의 리뷰는 손댈 수 없음
