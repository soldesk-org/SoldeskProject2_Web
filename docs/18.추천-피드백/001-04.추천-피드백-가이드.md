## 1. 서버 접속 정보
------------------------------------------------------------------------
- Spring 로컬 개발 서버: `http://localhost:8081`(기존과 동일)
- 팀원의 AI 추천 Python 서버는 기존과 동일하게 별도로 켜야 함(12.음BTI/07 관련 문서, 기본 포트 8000) —
  이번 기능은 그 위에 이력/피드백 저장만 추가한 것으로, Python 서버 자체는 변경 없음

------------------------------------------------------------------------
## 2. 프론트 연동 시 알아둘 것
------------------------------------------------------------------------
1. `POST /api/recommendation/query` 요청 자체는 그대로다 — `Authorization` 헤더는 여전히 선택(없어도
   추천은 정상 동작). 다만 로그인 상태로 보내야 응답에 `history_id`가 채워지고, 그래야 피드백을 남길 수
   있다.
2. 응답의 `history_id`가 `null`이면(비로그인) 피드백 버튼 자체를 숨기면 된다 — "로그인하면 이 추천에
   피드백을 남길 수 있어요" 같은 안내를 보여주는 것을 권장.
3. `history_id`가 있으면 👍/👎 버튼을 노출하고, 클릭 시 `PATCH /api/recommendation/{historyId}/feedback`을
   호출한다. 같은 이력에 다시 눌러도 에러 없이 값이 덮어써진다(마음이 바뀌면 다시 눌러도 됨).
4. 새 추천을 요청할 때마다(같은 화면에서 다시 질문해도) `history_id`가 매번 새로 발급된다 — 이전 질문의
   피드백 버튼 상태를 그대로 들고 있지 말고, 새 응답을 받을 때마다 버튼 상태를 초기화해야 한다.

## 3. API 상세
------------------------------------------------------------------------
### 3-1. 추천 요청 (기존 API, `history_id` 필드만 추가됨)
```
POST http://localhost:8081/api/recommendation/query
Authorization: Bearer {accessToken}   (선택)
Content-Type: application/json

{ "text": "강남에 있는 분위기 좋은 파스타집 추천해줘", "x": 127.0276, "y": 37.4980, "radius": 3000, "size": 10 }
```
응답(200)
```json
{
  "analysis": { "location": ["강남"], "category": ["양식"], "...": "..." },
  "recommendation_rule": "CATEGORY_BASED",
  "data_notice": "...",
  "total_candidates": 12,
  "recommendations": [ "..." ],
  "history_id": 1
}
```
로그인 안 했거나 토큰이 무효면 `history_id: null`.

### 3-2. 추천 피드백 제출 (신규)
```
PATCH http://localhost:8081/api/recommendation/{historyId}/feedback
Authorization: Bearer {accessToken}   (필수)
Content-Type: application/json

{ "wasHelpful": true }
```
성공 응답(200)
```json
{ "success": true, "message": "피드백이 저장되었습니다." }
```
실패 응답(404, 본인 이력이 아니거나 존재하지 않음)
```json
{ "success": false, "code": "RECOMMENDATION_HISTORY_NOT_FOUND", "message": "피드백을 남길 추천 요청 이력을 찾을 수 없습니다." }
```
실패 응답(401, 로그인 안 함)
```json
{ "success": false, "code": "NOT_LOGGED_IN", "message": "로그인이 필요합니다." }
```

------------------------------------------------------------------------
## 4. 에러 코드
------------------------------------------------------------------------
| code | 상황 | HTTP |
|---|---|---|
| RECOMMENDATION_HISTORY_NOT_FOUND | 이력이 없거나 본인 소유가 아님 | 404 |
| NOT_LOGGED_IN | 피드백 요청에 로그인 토큰이 없음/무효 | 401 |
