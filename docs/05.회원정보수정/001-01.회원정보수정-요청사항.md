## 기능 정리하기
------------------------------------------------------------------------
현재 해당 기능은 프론트 연결하지 않고 개발만 하기
회원정보수정에서 현재 입력받은 이메일, 비밀번호, 비밀번호확인, 닉네임, 전화번호 모두 수정이 가능하게
대신 소셜로그인 나중에 만들건데 소셜로그인으로 로그인 한 경우는 비밀번호 수정 불가
아 그리고 이메일, 전화번호는 수정 할 때 무조건 인증 다시 할 수 있도록 (회원가입에서 사용하는 기능들)
그리고 회원정보 수정 페이지에 들어오면 비밀번호 및 전화번호를 제외하고 전체 자동으로 채워줘야 함

------------------------------------------------------------------------
##  입력받는 값
------------------------------------------------------------------------
이메일, 비밀번호, 닉네임, 전화번호
