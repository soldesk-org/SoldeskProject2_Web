## 1. 이제 뭐가 달라졌나
------------------------------------------------------------------------
- **더 이상 `SoldeskProject2_Python/review-filter` Python 서버를 켤 필요가 없다.** 삭제됨.
- `.env`에 `REVIEW_FILTER_BASE_URL`을 넣을 필요도 없다(항목 자체가 `.env.example`에서 제거됨).
- 리뷰 작성(`POST /api/reviews`)/수정(`PATCH /api/reviews/{id}`), 오픈채팅 메시지 전송 시 욕설 필터가
  Spring Boot 서버 프로세스 안에서 즉시 처리된다 — 별도 서버가 꺼져있어서 필터가 무력화되는 경우의 수
  자체가 없어짐.

## 2. 코드에서 어떻게 쓰나
------------------------------------------------------------------------
호출부 코드는 17(리뷰-필터링) 때와 100% 동일하다 — 바뀐 게 없다:
```java
if (reviewFilterClient.containsProfanity(content)) {
    throw new CustomException(ErrorCode.REVIEW_CONTENT_PROFANITY);
}
```
새로운 텍스트 검사가 필요한 곳이 생기면 그냥 `ReviewFilterClient`를 주입받아 `containsProfanity(text)`를
호출하면 된다(이름이 "Review"이지만 실제로는 범용 한국어 욕설 판별기 — 19.오픈채팅도 이미 이렇게
재사용 중).

------------------------------------------------------------------------
## 3. 판정 범위 (기억해둘 것)
------------------------------------------------------------------------
korcen 원본의 general/minor/sexual/belittle/race/parent/special/politics 8개 카테고리만 이식되어 있다.
영어/일본어/중국어 욕설 판별은 지원하지 않는다(원래도 안 쓰던 기능). 새로 지원이 필요해지면
`KorcenProfanityFilter`에 원본 소스(github.com/KR-korcen/korcen)의 english/japanese/chinese 관련
데이터·로직을 추가로 이식하면 된다 — 다만 `better_profanity`(영어 욕설 라이브러리) 같은 원본의 외부
의존성까지 그대로 옮기려면 별도 검토가 필요하다.

------------------------------------------------------------------------
## 4. 데이터/패턴을 업데이트하고 싶다면
------------------------------------------------------------------------
korcen 원본이 업데이트되면(새 오탐 패턴 추가, 새 욕설 패턴 추가 등), `KorcenProfanityFilter`의 해당
`static final String[]` 배열에 수동으로 반영해야 한다 — 자동 동기화되는 구조가 아니다(pip 패키지처럼
버전 업그레이드만으로 갱신되지 않음, 원본 소스를 다시 확인하고 필요한 부분만 옮겨야 함).

------------------------------------------------------------------------
## 5. 알려진 한계
------------------------------------------------------------------------
- `highlight_profanity`(욕설 부분 강조 표시) 기능은 이식하지 않음 — boolean 판정만 필요
- 001-03 3장에 기록된 것처럼, 원본 라이브러리 자체의 데이터-데모 불일치로 인해 극히 일부 특수한 자모
  조합(예: "ㅣ"가 낱개로 쓰이는 경우 "ㅏ"로 정규화됨)에서는 원본과 동일하게 예상 밖의 결과가 나올 수
  있음 — 이는 Java 포트만의 문제가 아니라 원본에도 동일하게 존재하는 특성
