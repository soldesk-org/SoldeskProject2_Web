# 주차장 정보 - 가이드
------------------------------------------------------------------------
[001-02.주차장-정보-분석-설계.md](001-02.주차장-정보-분석-설계.md), [001-03.주차장-정보-구현-테스트.md](001-03.주차장-정보-구현-테스트.md) 참고

**(2026-07-27 전면 개정)** data.go.kr 기반 "DB 동기화 후 조회" 방식에서 **서울 열린데이터광장 기반
실시간 조회**로 전환됨(전국 176만여 건 규모+반경검색 불가+원인불명 에러 때문, 001-02 9장/001-03 5장
참고). 이 문서는 새 방식 기준으로 다시 썼다 — 예전 동기화 관련 내용(2장~5장 구버전)은 완전히 대체됐다.

------------------------------------------------------------------------
## 1. 서버 접속 정보
------------------------------------------------------------------------
- 로컬 개발 서버: `http://localhost:8081`
- 근처 주차장 조회는 로그인 불필요, 별도 동기화 절차 없음(요청 시 매번 실시간 조회).

------------------------------------------------------------------------
## 2. 서비스키 준비
------------------------------------------------------------------------
서울 열린데이터광장(https://data.seoul.go.kr) 에서 **"서울시 주차장 정보"(GetParkInfo)** 인증키를 발급받아
`.env`에:
```
SEOUL_PARKING_SERVICE_KEY={발급받은 인증키}
```
값을 채우면 바로 동작한다(별도 동기화 트리거 없음). `SEOUL_PARKING_BASE_URL`은 기본값
(`http://openapi.seoul.go.kr:8088`)을 그대로 쓰면 됨, 생략 가능. 서비스키가 없으면
`GET /api/parking-lots/nearby`가 예외 없이 그냥 빈 배열을 반환한다.

(참고) 예전 `PARKING_DATA_SERVICE_KEY`(data.go.kr)도 `.env`에 남아있지만 현재 코드는 이 값을 읽지
않는다 — 나중에 전국 단위로 되돌릴 경우를 대비해 지우지 않았을 뿐이다.

------------------------------------------------------------------------
## 3. 기능별 호출 흐름
------------------------------------------------------------------------
### 3-1. (일반) 음식점 상세에서 인근 주차장 표시
1. 음식점 상세 조회(`GET /api/restaurants/{id}`, 07)로 받은 `latitude`/`longitude`를 그대로
   `GET /api/parking-lots/nearby`에 넘긴다 — 별도로 좌표를 다시 구할 필요 없음
2. 서버가 그 요청 안에서 서울 열린데이터광장 전체(최대 3회 호출)를 실시간으로 받아와 거리 계산 후
   반환한다 — 응답까지 약 1초 내외 걸림(001-03 5-3장 실측)
3. 응답이 빈 배열이면 "주변에 주차장 정보가 없습니다" 안내(서울시 밖 좌표이거나, 반경 내에 좌표가 있는
   주차장이 없는 경우 — 둘 다 빈 배열, 구분 안 함)
4. **서울시 밖 좌표는 처음부터 결과가 없다** — 이 API 자체가 서울시 한정이기 때문(001-01 10장)
5. `feeType`이 "정보없음"이면 유료인데 구체적인 요금 필드가 비어있는 경우

------------------------------------------------------------------------
## 4. API 상세
------------------------------------------------------------------------
### 4-1. 근처 주차장 조회
```
GET http://localhost:8081/api/parking-lots/nearby?latitude=37.4979&longitude=127.0276&radiusM=2000
```
`radiusM`(선택, 기본 1000, 최대 5000)으로 반경 조절 가능. 좌표는 서울시 안이어야 결과가 나온다.

응답(200, 2026-07-27 실 서버 실측):
```json
[
  {
    "parkingLotId": 2877728, "name": "양재역 공영주차장(시)", "address": "서초구 양재동 23-0",
    "latitude": 37.483518, "longitude": 127.034357, "distanceM": 1707, "totalSpaces": 885,
    "feeType": "유료", "feeSummary": "기본 5분 400원, 추가 5분당 400원"
  },
  {
    "parkingLotId": 3187200, "name": "반포천 공영주차장(파미에)(시)", "address": "서초구 반포동 118-3",
    "latitude": 37.504517, "longitude": 127.007933, "distanceM": 1885, "totalSpaces": 1186,
    "feeType": "유료", "feeSummary": "기본 5분 550원, 추가 5분당 550원"
  }
]
```
반경 내에 없거나(서울시 밖 포함) 서비스키 미설정이면 `[]`.

------------------------------------------------------------------------
## 5. 에러 코드
------------------------------------------------------------------------
| code | 상황 | HTTP |
|---|---|---|
| PARKING_DATA_SERVICE_UNAVAILABLE | 서울 열린데이터광장 API 통신 실패/오류 응답(`INFO-000` 아닌 결과코드) | 500 |

서비스키 미설정 자체는 에러가 아니라 그냥 빈 배열 응답(3장 참고).
