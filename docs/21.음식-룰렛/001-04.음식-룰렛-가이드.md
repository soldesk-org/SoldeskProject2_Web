## 1. 접속 정보
------------------------------------------------------------------------
`http://localhost:8081/roulette-test.html` — 로그인 불필요. 룰렛 자체(칸 구성/회전/당첨 판정)는 API 호출
없이 동작하지만, "내 주변 맛집 찾기"(2026-07-26 추가)는 07(음식점-메뉴-검색)의 기존 공개 API를 호출한다.

------------------------------------------------------------------------
## 2. 사용법
------------------------------------------------------------------------
1. 카테고리 아이콘(한식/양식/중식/일식/분식/패스트푸드/아시안/술집/뷔페/카페-디저트) 중 먹고 싶은 것들을
   탭해서 선택 — 최소 2개 이상 선택하면 "룰렛 만들기" 버튼이 활성화됨
2. "룰렛 만들기" → "START" 클릭 → 4.2초 회전 후 당첨 결과가 모달로 표시됨
3. "📍 내 주변 맛집 찾기"를 누르면 현재 위치(브라우저가 위치 권한을 물어봄) 주변에서 그 카테고리를 파는
   실제 음식점 최대 5곳을 보여준다 — 카카오맵 링크로 바로 이동 가능
4. 당첨된 카테고리가 마음에 안 들면 "이건 빼고 다시 돌리기"로 그 카테고리만 빼고 재도전 가능
5. 처음부터 새로 만들려면 "처음부터 다시 만들기"

------------------------------------------------------------------------
## 3. 알아둘 것
------------------------------------------------------------------------
- 결과는 저장되지 않는다 — 새로고침하면 선택했던 카테고리도 전부 사라진다(001-02 2-1장, 의도된 설계)
- 룰렛 각도 계산 자체는 100% 클라이언트에서 `Math.random()`으로 이뤄진다 — 스핀은 항상 즉시 시작된다
- "내 주변 맛집 찾기"는 위치 권한을 거부하면 강남역 인근 기본 좌표로 대체되어 계속 동작한다
- 카테고리는 07의 `GET /api/restaurants/categories`에서 실시간으로 받아오므로, categoryId 값을 코드에
  하드코딩하지 않는다(환경마다 값이 다를 수 있음)

------------------------------------------------------------------------
## 4. API 상세 (신규 API 없음, 기존 07 API 재사용)
------------------------------------------------------------------------
```
GET /api/restaurants/categories
GET /api/restaurants/filter?categoryId={id}&minLat=&maxLat=&minLng=&maxLng=&size=5
```
두 API 모두 07에 이미 있던 공개 API(로그인 불필요)를 그대로 호출한다 — 상세 스펙은
`docs/07.음식점-메뉴-검색/` 문서 참고.
