소셜로그인에서는 로그인하면 기본 정보에서 전반적인건 다 자동으로 끌고 올테니 따로 입력받거나 인증하진 않겠음
아 그리고 이미 이메일로 가입을 했는데 카카오톡나 간편로그인으로 로그인 할 경우 동일한 이메일이 되어버리니 그럴 경우 실패처리하고 이미 생성된 계정이 있다
그 계정으로 로그인하라 라고 해줘야 함
회원정보수정에서도 말했겠지만 소셜로그인 한 계정은 비밀번호 수정을 할 수 없고 만약 끌고 온 정보 중에 없는 이메일이나 전화번호는 추가적으로 등록할 순 있음 대신 인증은 필수

각 플랫폼별 연동 해제 API
네이버
- GET https://nid.naver.com/oauth2.0/token?grant_type=delete&client_id=...&client_secret=...&access_token=...&service_provider=NAVER
- 토큰 삭제 방식
네이버 연결 끊기
- Callback URL http://localhost:8081/api/auth/naver/unlink-callback
- 연결 끊기 콜백을 설정할 경우 사용자가 '네이버 프로필 > 연결된 서비스 관리'에서 연결 끊기를 진행하거나, 네이버 회원을 탈퇴한 경우 알려 드립니다.
구글
- POST https://oauth2.googleapis.com/revoke?token={token}
- access_token 또는 refresh_token 무효화
카카오
- POST https://kapi.kakao.com/v1/user/unlink
- Header에 Authorization: Bearer {access_token}

그리고 다 만든 다음에 필요한지 이야기 해줘야 하는 것들
- 소셜로그인을 개발중에서 프로덕트? 로 공개해야 하는지 (지금으로는 필요 없을수도 있음)
