# Python 서버 배포 아키텍처 계획 (2026-07-30 논의, 아직 미구현)

> **상태: 계획 단계.** 아래 내용은 실행하지 않고 문서로만 남겨둔 것 — 곧 실제로 진행할 예정이라
> 방향만 먼저 기록해둔다. 실행 여부/세부 절차는 착수 시점에 다시 확정한다.

## 1. 배경 / 문제

- `SoldeskProject2_Python`의 `main` 브랜치는 (이 계획에서는) 코드를 **올리기만 하는 용도**로만
  쓴다 — 그 코드를 그대로 자동 배포하는 CI/CD는 이 계획 범위에 포함하지 않음.
- 문제는 **AI 모델(키워드 추출/추천, `keyword-extraction`, GPU 필요, `torch`/`transformers` 사용)을
  어디서 실행시킬 것인가**: GPU가 달린 VM은 용량 대비 비용이 비싸고 구하기도 어려움.

## 2. 결정된 방향

### 2-1. AI 추천 모델(keyword-extraction, GPU 필요) → 로컬 컴퓨터에서 실행

- Web 백엔드(Azure VM)가 GPU를 갖춘 **팀원 로컬 컴퓨터**로 요청을 보내는 구조.
- 로컬 컴퓨터가 요청을 받을 수 있게 하는 방법: **ngrok 또는 Cloudflare Tunnel**.
  - IP 직접 노출 + 포트포워딩 방식은 학원 네트워크에서 포트를 열어줘야 하는 번거로움이 있어 제외.
  - ngrok/Cloudflare Tunnel은 로컬 → 외부로 나가는 연결만 있으면 되므로 포트포워딩/방화벽 설정이
    필요 없음.
  - **Cloudflare Tunnel 권장**(ngrok 대비): 이미 보유 중인 도메인(`eattyway.com`)에 서브도메인
    (예: `ai.eattyway.com`)을 고정으로 매핑해 무료로 계속 같은 주소를 유지할 수 있음. ngrok 무료
    플랜은 재시작마다 URL이 바뀌어서 Spring 쪽 설정(`recommendation.base-url` 등)을 매번 갱신해야
    하는 단점이 있음.
  - **알려진 제약**: 그 로컬 컴퓨터가 켜져 있고 인터넷에 연결되어 있어야만 AI 추천 기능이 동작함 —
    컴퓨터를 끄면 그 순간 AI 추천 기능만 죽음(다른 기능엔 영향 없음, VM은 그대로 살아있음). 팀이
    감수 가능한 리스크인지 사전 확인 필요.

### 2-2. 영수증 OCR / 사업자등록증명원 OCR·진위여부 → 기존 Azure VM에 배포

- 이 두 서비스는 GPU가 필요 없어 기존 VM(`SoldeskProject1`)에 그대로 배포.
- 서버 포트를 나눠서 Python 서버 2개를 별도로 실행(예: receipt-ocr용 포트 하나, 사업자등록
  진위확인용 포트 하나 — 기존 `receipt-biz-verify` 서비스가 이미 이 두 기능을 담당 중, 필요시
  분리 여부는 착수 시 재확인).
- Nginx 등 리버스 프록시를 앞단에 두고, 서브도메인(예: `api.eattyway.com`)으로 Web에서 요청하도록
  구성 — IP:포트 직접 호출 대신 도메인 기반 호출로 전환.

## 3. 실행 전 확인 필요한 사항 (2026-07-30 기준 평가)

| 항목 | 내용 |
|---|---|
| 기술적 가능 여부 | 2-1, 2-2 둘 다 기술적으로 문제없이 가능함(표준적인 패턴) |
| VM NSG | HTTP(80)/HTTPS(443)는 이미 열려있어(VM 최초 생성 시 설정) 추가 방화벽 작업 불필요 |
| HTTPS | 서브도메인에 certbot(Let's Encrypt)으로 무료 인증서 발급 가능 |
| DNS | `eattyway.com`에 서브도메인 A 레코드를 VM 공용 IP로 추가 필요 |
| **VM 메모리 리스크 (중요)** | 이 VM은 1GiB 메모리(실사용 약 846MB) — MariaDB+Redis+Jenkins+Spring Boot가 이미 떠 있는 상태에서 OCR 모델(rapidocr/OpenCV) 쓰는 Python 서버 2개를 추가로 올리면, Jenkins 설치 때 세 번 겪었던 것과 같은 메모리 부족 행 문제가 재발할 가능성이 있음. 2GB 스왑을 이미 잡아뒀지만(`docs/00.공통/VM-재구축-전체가이드.md` 13장) 그것만으로 충분한지는 실제로 올려봐야 확인 가능 — 부족하면 스왑 증설 또는 VM 사양 업그레이드 검토 필요 |
| 로컬 컴퓨터 상시 가동 | AI 추천 기능은 그 컴퓨터가 꺼지면 같이 죽음 — 팀 내 합의 필요 |
