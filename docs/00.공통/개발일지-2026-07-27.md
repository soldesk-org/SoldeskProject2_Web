  직접 거리 계산하는 방식으로 설계 변경
- 기존 data.go.kr 관련 코드(`ParkingDataClient`, 스케줄러, `parking_lots` 테이블)는 삭제하지 않고 스케줄러

- 실 서버로 강남역 좌표 테스트 → 약 1.1초 만에 실제 주차장 데이터가 거리순+요금 정보와 함께 정상 반환됨을 확인

## 2. 주차장 중복 표시 버그 수정 (15.주차장-정보, 후속)
- 같은 이름의 주차장이 거리·요금이 똑같은 채로 여러 번 반복 출력되는 문제 발견
- 원인은 버그가 아니라 서울 열린데이터광장 API 자체가 노상 주차장을 개별 주차 칸 단위로 별도 행을 주고
  있었던 것(예: 같은 주차장이 38개 행으로 쪼개져 있었음)
- 같은 코드끼리 거리 계산 전에 먼저 병합하는 로직 추가(대표 좌표는 그룹 첫 행, 구획수는 합산) — 실 서버로
  재검색해서 정상 병합 확인

## 3. 길찾기 기능 신규 개발 (22.길찾기, 신규 기능)
- 검색한 음식점까지 자동차 길찾기 기능 요청 — NCP Maps의 Direction 5 API를 서버가 대신 호출해주는 프록시
  방식으로 구현(지도 렌더링용 공개 키와 달리 Client ID/Secret 인증이 필요한 서버 전용 API)
- `curl`로 NCP 원본 응답을 먼저 직접 확인해서 추정 없이 정확하게 구현(경로 좌표/거리/소요시간/통행료/택시요금이
  한 응답에 다 포함되어 있음을 확인)
- 음식점 상세 패널에 길찾기 버튼 추가 — 클릭 시 현재 위치부터 해당 가게까지 경로를 지도에 선으로 그리고
  거리/소요시간/택시요금을 텍스트로 요약 표시
- Playwright로 위치를 강남역 좌표로 모킹해서 실제 브라우저로 검증, 경로선과 요약 텍스트 정상 확인
- 이번 범위는 자동차 경로만 포함(도보/대중교통/경유지/턴바이턴 안내는 제외)
