## 1. 새 프론트엔드 전면 교체 + 백엔드 연동
- 기존 테스트용 static HTML 페이지들을 전부 정리하고, 새로 받은 Tailwind 기반 정식 프론트엔드 파일로 교체
- 공용 인증 모듈(`api.js`) 작성 — 로그인/로그아웃, 로그인 필요 체크, 역할별 랜딩 페이지 분기, 네비게이션
  인증 UI 초기화까지 한 곳에서 관리
- 회원가입/로그인/약관 페이지, 탐색(explore)/AI 추천(recommend)/음BTI(taste-quiz)/영수증 업로드/마이페이지/
  오픈채팅/사업자 마이페이지까지 전 페이지를 실제 백엔드 API와 연동
- CSS는 Tailwind CLI로 재빌드, 각 페이지마다 로그인/실사용 흐름을 Playwright로 직접 띄워서 검증(탐색/마이페이지/
  채팅 실시간 메시지/사업자 권한 가드까지 전부 통과)

## 2. 클린 URL 라우팅 적용
- 전체 페이지 주소가 `.html`로 끝나던 걸 `/mypage` 같은 확장자 없는 형태로 나오도록 `PageRoutingController` 신규 작성
- 화이트리스트에 있는 페이지명만 forward, 없으면 404 처리
- 캐치올 라우팅 패턴이 오픈채팅 WebSocket 핸드셰이크(`/ws-chat`)까지 가로채서 실시간 채팅이 끊기는 문제를
  발견 — 정규식에 `/ws-chat`은 제외하는 예외 처리 추가로 해결, 두 브라우저로 실시간 채팅 재검증
- 404 처리 중 전역 예외 핸들러가 이를 500으로 바꿔버리는 문제도 함께 발견해서 `sendError()` 직접 호출로 수정

## 3. 탐색(explore) 페이지 지도/마커 버그 수정
- 지도 영역 좌표 계산 API를 잘못된 메서드로 호출하고 있어서 필터 검색이 조용히 빈 결과를 내던 버그 수정
- 최소가격 필터가 0원도 활성 필터로 취급되어 가격 정보 없는 매장을 전부 제외하던 문제 수정
- 카테고리 미매칭 매장에 기본 파란 마커가 뜨던 문제를 브랜드 컬러의 커스텀 마커로 교체
- 상세 패널이 사이드바 위로 겹쳐 나오던 레이아웃 버그, 주차장 이름에 괄호가 남아있던 표시 문제도 함께 수정
---
## 4. AI 추천(recommend) 페이지 대형 버그 수정 + UX 개선
- 추천 결과 카드에 매장명/이유/위치가 안 뜨던 문제의 원인이 백엔드 응답 필드명(snake_case)과 프론트 코드
  (camelCase)의 불일치였음을 확인하고 전면 수정 — 즐겨찾기 토글도 같은 원인으로 같이 고장나 있었음
- "AI 답변이 마음에 들었어요/아니요" 피드백을 질문 한 번당 한 번만 누르도록 잠금 처리, 누른 뒤엔 버튼 비활성화
- 로그아웃 상태에서 피드백 버튼 영역이 통째로 사라져 안내문구까지 안 보이던 문제 수정
- 추천 후 "산책/카페 어때요" 후속 추천 문구를 자연스럽게 다듬고, 결과 리스트 디자인을 메인 검색과 통일
- 검색 대기 화면을 토스 스타일 스켈레톤 로딩 UI로 교체
---
## 5. 마이페이지 신규 회원정보수정 화면 추가
- 닉네임/전화번호/비밀번호/프로필 사진을 수정할 수 있는 `mypage-edit` 페이지 신규 개발 — 비밀번호 재인증
  게이트를 먼저 통과해야 수정 폼이 열리는 구조, 한 화면에 스크롤 없이 꽉 차는 레이아웃으로 구성
- 마이페이지 프로필 카드/통계 박스 레이아웃 정렬 및 크기 불일치 수정
