## 6. 참고 — 이번 프로젝트에서 검토 후 대체/제외된 것
------------------------------------------------------------------------
PPT에서 "왜 이걸 안 썼는지" 질문이 나올 수 있어 간단히 남겨둠:
- **네이버 지역 검색 API** — 위치기반 반경 검색을 지원하지 않는 한계 확인 후 카카오 로컬 API로 전환
  (07 001-05 참고, 코드에도 남아있지 않음)
- **소상공인시장진흥공단_상가(상권)정보 API** — 데이터가 오래되고 업종 분류가 부정확해 카카오 로컬 API로
  대체(07 001-06 참고, 코드에도 남아있지 않음)
- **한국교통안전공단_주차정보 제공 API**(data.go.kr, 서비스ID B553881) — 15(주차장-정보) 1차 구현에서
  2026-07-26까지 실제로 썼던 API. 전국 176만여 건(중복 다수) 규모에 반경검색이 아예 안 되고, 대량 조회
  시도 중 원인불명의 `-999` 에러까지 겹쳐 2026-07-27 서울 열린데이터광장으로 전환(2장 참고). **코드는
  삭제하지 않고 주석 처리만 해서 남아있음**(`ParkingDataClient`/`ParkingSyncService`/
  `ParkingSyncScheduler`) — 나중에 전국 단위가 다시 필요해지면 되돌릴 수 있음, `docs/15.주차장-정보/
  001-01` 10장 참고
