## 확인된 사항 (2026-07-22, 설계 착수 전 확인)
------------------------------------------------------------------------
- **음BTI**: 다른 팀원이 담당 — 이번엔 필드(컬럼)만 만들어두고, 값을 채우는 퀴즈/자동계산 로직과 값을
  설정하는 API는 이번 범위에 포함하지 않는다. 항상 `null`로 시작.
  **(2026-07-23 후속)** 그 팀원의 퀴즈/채점 로직을 실제로 연동함 — `docs/12.음BTI` 참고.
- **방문기록**: 영수증으로 방문 인증까지 성공한 상태로 작성한 리뷰의 그 가게들을 보여준다(새로운 "길찾기
  클릭 추적" 같은 인프라를 새로 만들지 않음).
- **비밀번호 수정 제한**: "소셜로그인 시 수정 불가"는 이미 05(회원정보수정)에 구현되어 있음(재확인만 하고
  마이페이지는 그 API를 그대로 재사용).

## 이번 범위 정리
------------------------------------------------------------------------
- 프로필 조회(닉네임/이메일/전화번호/음BTI) — 이메일은 표시만, 수정 불가
- 프로필 수정(닉네임/전화번호/비밀번호) — 기존 05 기능 재사용, 신규 개발 없음
- 즐겨찾기 등록/해제/목록 — 신규 개발(기존엔 조회용 읽기 전용 엔티티만 있었음)
- 방문기록 목록 — 신규 개발(영수증 인증된 리뷰 기준)
- 내 리뷰 목록 — 신규 개발(회원 기준 리뷰 조회 API가 없었음)
- 음BTI — 필드만 추가, 값 설정/계산 로직은 이번 범위 제외

상세 설계는 [001-02.마이페이지-분석-설계.md](001-02.마이페이지-분석-설계.md) 참고.

## 추가 요청 (2026-07-22, "다 되어야 해" 확정 지시)
------------------------------------------------------------------------
마이페이지 1차 구현이 "정보만 보여주는" 수준(즐겨찾기/방문기록/내 리뷰 목록만 조회 가능, 수정 폼 없음)에
그쳐 있다는 지적과 함께, 아래 세 가지가 명시적으로 추가 요청됨:
- **리뷰 작성·수정·삭제**: 작성/조회는 이미 있었음(10.리뷰) — 수정/삭제가 새로 추가됨(10 001-02 2-7장)
- **즐겨찾기 등록·취소**: 이미 구현되어 있었음(001-02 3-2장) — 추가 개발 없이 그대로 유지
- **검색 기록 조회·삭제**: 완전히 새로운 기능 — DB-테이블설계.md 5-3장에 설계만 있던 `search_histories`
  테이블을 처음 실사용(001-02 3장 갱신 참고). 07 001-02 8-2장에서 "요구사항에 없어 이번 범위에서 제외함"
  으로 남겨뒀던 항목이 이번에 정식으로 범위에 들어옴.

## 추가 요청 2 (2026-07-22, 프로필 수정 UI 부재 지적)
------------------------------------------------------------------------
"마이페이지에서 회원정보가 보여만 지고 수정이 안되고 있다"는 지적으로 실제 수정 화면을 요청받음. 요구사항
원문 요약:
- 이메일은 수정 안 되게, 대신 보여주기는 함(001-01 원문과 동일 방침 재확인)
- 비밀번호는 소셜로그인 시 수정 안 되게, 그리고 **안 보여줌**(입력란 자체를 숨김)
- 나머지 정보(닉네임/전화번호/프로필 사진)는 플레이스홀더로 현재값을 보여주면서 수정 가능해야 함

**구현 결과**: 정적 테스트 페이지 `mypage-test.html`(신규, `tmp-map-test.html`과는 별개 파일)을 새로 만들어
프로필 조회/수정 전체 흐름을 구현. "마이페이지 접속 시 비밀번호를 정확하게 입력해야만 수정 화면으로 들어갈
수 있게" 해달라는 후속 요청까지 함께 반영되어, 프로필 수정 폼 전체가 비밀번호 재확인 게이트 뒤에 있다.
상세 설계는 001-02 3-7장, 구현/검증은 001-03 6장, API는 `docs/05.회원정보수정/001-02` 5-11장
(`POST /api/members/me/verify-password`, 엔드포인트 자체는 05 소관) 참고.
